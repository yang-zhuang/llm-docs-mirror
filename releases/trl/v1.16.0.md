## Features

### 🛠️ TRL now trains on AWS Trainium

<img width="1672" height="941" alt="Neon Warehouse_ AWS and Trainium Support" src="https://github.com/user-attachments/assets/dcb6e2a1-0f7c-4635-819b-a1ec6f5e143b" />

The fused LM head from v1.15 is what made Neuron tractable; the remaining gaps are closed here. There is a [guide](https://huggingface.co/docs/trl/neuron) to go with it.

Neuron recompiles once per input shape, so an unpadded run stalls about a minute on every new sequence length. `pad_to_multiple_of` now defaults to `"auto"`: 128 on Neuron, `None` elsewhere, so nothing changes on GPU. Trainium2, Qwen3-0.6B SFT, 20 steps: **130 s with the default against 260 s without**.

### 🌳 Tree attention for AsyncGRPO

AsyncGRPO now packs every micro-batch row as a **prefix tree** instead of a flat sequence. Multi-turn and multi-generation rollouts repeat a lot of prefix: on a shared prompt, those tokens used to be forwarded once per row. Tree packing forwards them once.

```text
rollout 0:  [ prompt ] [ completion A ]              prompt ──┬── completion A ── later turn
rollout 1:  [ prompt ] [ completion B ]        =>             └── completion B
rollout 2:  [ prompt ] [ completion A ] [ … ]
```

Chains without a fork collapse into segments, and each segment's queries attend to the K/V gathered along its root-to-segment path in a single FA3 varlen call. No mask tensor: every layer except attention runs once per unique token, and only K/V is duplicated along shared prefixes.

Qwen3-1.7B, 32K tokens per rollout, forward + backward:

| layout | packing ratio | sequence packing | tree packing | peak GiB |
| --- | --- | --- | --- | --- |
| shared prompt | 1.00 | 8677 ms | 8737 ms (0.99×) | 35.2 → 35.2 |
| shared prompt | 2.29 | 8266 ms | **4341 ms (1.90×)** | 35.2 → 18.0 |
| shared prompt | 3.37 | 8179 ms | **2755 ms (2.97×)** | 35.2 → 13.6 |
| nested fork | 1.60 | 8557 ms | 6217 ms (1.38×) | 35.2 → 23.8 |
| nested fork | 3.56 | 8172 ms | **2635 ms (3.10×)** | 35.2 → 13.5 |

There is no `packing` option to choose: with nothing shared a tree row is exactly the old sequence packing, at a ~1% cost.

by @AmineDiro in https://github.com/huggingface/trl/pull/7328

### Muse Spark Open

Support for [`meta-models/Muse-Spark-Open-816B-A42B`](https://huggingface.co/meta-models/Muse-Spark-Open-816B-A42B): the tiny-model script, coverage in the VLM tests (SFT, DPO, KTO, chat-template utils, fused LM head), and a LoRA SFT example on 8 nodes of 8×H100 with `DistributedConfig(fsdp_size=64, ep_size=8)`, token dispatch and packing. Measured at **14.2 s/step, 131k tokens/step, 40.2 GB per GPU**.

Needs `transformers>=5.20.0`; the adapter save additionally needs [transformers#49500](https://github.com/huggingface/transformers/pull/49500) with peft 0.21.2.

by @qgallouedec in https://github.com/huggingface/trl/pull/7536

## Fixes

* **Fix silently wrong `torch.compile` results in the Triton loss kernels on torch < 2.11.** `torch_compile=True` trained with `loss=0.0` and `grad_norm=nan` at every step. Inductor passes scalar kernel args as `constexpr` before torch 2.11, the `.to(tl.float32)` casts raised on those, and Inductor then assumed every input was mutated and miscompiled. By @albertvillanova in https://github.com/huggingface/trl/pull/7688
* **Fix FSDP2 vLLM colocate weight sync for tied-embedding models** by @Abdennacer-Badaoui in https://github.com/huggingface/trl/pull/7647
